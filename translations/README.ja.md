## なぜ

Pock、PockV2 および同様のものは Dock を Touch Bar に配置できますが、多くのことを行い、日常使用では bar が消えたり応答しなくなったりします。DockTouchBar は 1 つの仕事に専念し、それをうまくやります。

**シンプル**

- 1 つの仕事: Touch Bar 上の Dock。ウィジェット、プラグインなし。
- メニューバーに数個のスイッチ、それ以外の設定は不要。
- ネイティブ Swift と AppKit、サードパーティ依存関係なし。ピクセルアートシーンはソースに含まれています。

**エレガント**

- macOS アイコンとシステム Touch Bar スクローラーを使用。ピン留めされていない実行中アプリは左に表示され、最新のものが最初; ピン留めされたアプリは Dock の順序を保持します。アプリを閉じるときは現在の表示領域を保持します。
- ジェスチャーは邪魔にならない: タップはすぐに機能します（ダブルタップが来るかどうか確認するために待機しません）、長押しはアイコンの下に静かなプログレスバーを表示し、Touch Bar の右端に「閉じています...」カウントダウンが表示されるため、指はそれを隠しません。4 つの季節を切り替えられるピクセルアートシーンとして描かれています。早期に離すとキャンセル。
- 素早いタップは正しく感じられます: 最後のタップが常に勝ちます。システムがデスクトップ切り替えを落としたり、何かがフォーカスを盗んだ場合でも、静かに正しく戻し、キーボード、マウス、トラックパッドに触れると停止します。
- あなたの言語を話します（12 言語、英語から 简体中文 と 日本語 まで）、オプションの許可は 1 つだけ要求します。

**効率的**

- イベント駆動型のアプリとウィンドウ更新。M1 MacBook Pro 上の以前の測定値（Dock が表示され、アイドル時）: **0.0% CPU**、**0 アイドルウェイクアップ**、約 **32 MB** のメモリ。\*
- 固定遅延ではなく Mac に適応します: デスクトップ切り替えはシステム独自の「完了」シグナルを待機して結果を確認するため、アニメーションが遅い、オフ、またはマシンがビジーかどうかに関わらず正確なままです。
- アプリが起動または終了したときは、変更されたものだけが更新され、スクロール位置が保持されます。アイコンは 1 回ラスタライズされキャッシュされます。
- 自己修復: スリープ、スクリーンロック、Control Strip の再起動後に再接続するため、再起動する必要はありません。
- 安全に失敗: プライベート API は実行時に解決されます。macOS が削除した場合、その機能はクラッシュせず自動的にオフになります。
- プライバシー: アナリティクスやアカウントなし。Dock インタラクションはローカルで実行; 自動更新チェックと要求されたダウンロードは GitHub に接続します。設定はあなたの Mac に留まります。

<sub>\* リリースビルド。CPU は 2 秒間隔で 5 つの `top` サンプルから（すべて 0.0%）; ウェイクアップはカーネルのプロセスごとカウンター（1.10 では 20 秒間隔で 3 回読み込み）から（アイドルウェイクアップなし、すべての時間で割り込みウェイクアップなし; 1.8 の以前の実行では 0 ～ 7 割り込みウェイクアップ、システムイベントから）; メモリは `footprint` からの物理フットプリント（32 MB）。コーヒーカップ上のスチームはアプリではなくシステムのレンダープロセスで描画されます。</sub>

## 機能

| ジェスチャー | 動作 |
|---|---|
| **タップ** アイコン | アプリに切り替えるか、起動します。ウィンドウが別のデスクトップ（Space）にある場合はそのデスクトップにジャンプします |
| **ダブルタップ** | 現在のウィンドウを最小化します（黄色いボタンのように）。アクセシビリティ権限が必要です。もう一度タップして復元 |
| **長押し** | アプリを閉じ、常に何が起こったかを伝えます。保持している間はアイコンの下のプログレスバーが塗りつぶされ、右端に「閉じています...」カウントダウンが表示され、ピクセルアートの季節（メニューから選択可能）上に表示されます; 早期に離すとタップと同じ扱いになります。アプリは常に完全に終了します（⌘Q と同じ）、ウィンドウの数や最小化/隠れた状態に関わらず。Finder は終了できないため、すべてのウィンドウが代わりに閉じられます（最小化されたものも; 別のデスクトップにある場合は最初にそこへジャンプします）。アプリが「変更を保存していません」シートを待機しているか閉じない場合、Touch Bar はそれに切り替わり、デスクトップ全体を表示し、その旨を伝えます |
| **ゴミ箱** | タップするとゴミ箱ウィンドウが Finder で開きます; ダブルタップで最小化; 長押しで閉じます。ウィンドウが閉じている間は暗くなります（「実行中のアプリのみを表示」モードでは消えます） |
| **スワイプ** | アイコンがすべて表示されない場合はスクロール; アプリを閉じると現在の領域が表示されたままになります |
| **コーヒーカップ** (右端、動くスチームあり) | 休憩: Dock を一時的に隠し、Touch Bar をシステム（明るさ、音量）に返します。10 ～ 60 秒後に自動的に戻ります |
| **中央/最大化ボタン** (右端) | 前面アプリのウィンドウを中央に配置; もう一度タップすると最大化（使用可能な領域を埋める、ネイティブ全画面表示ではない）、もう一度タップすると中央に配置します。ウィンドウを自分で移動したかアプリを切り替えた場合は、最初に中央に配置され、アイコンはウィンドウの現在の状態に従います。アクセシビリティ権限が必要です |

メニューバーメニューは日常的なスイッチを保持します: Touch Bar に Dock を表示、実行中のアプリのみを表示（デフォルトでオフ: ピン留めされたアプリも表示; 暗くなるアプリ（ウィンドウがない Finder と閉じた ゴミ箱 を含む）は隠され、Finder は左端に座ります）、アイコンを中央に配置（表示されている場合; オーバーフローすると左から開始してスクロール）、中央/最大化ボタンを表示、ログイン時に起動。**設定...** は 3 ページを持つ設定ウィンドウを開きます:

- **設定** — アイコン間隔; コーヒーカップをタップした後の一時的な非表示時間（10 / 20 / 30 / 60 秒）; 中央配置されたウィンドウのサイズ（画面高さの 60 ～ 100%; 幅は高さと同じ、または画面幅の 50 ～ 100%）; ダブルタップで最小化; 長押しで閉じる（オフ / 1 / 2 / 3 / 5 秒）とそのスタイル（春/夏/秋/冬、Touch Bar での短いプレビュー付き）; システム Touch Bar コントロールへの譲渡（独立した スクリーンショット / 録画 と Fn スイッチ、デフォルトでオン）; 言語（システムに従う、または 12 言語のうち 1 つ — 設定ページの上部に表示; Touch Bar の長押しメッセージも翻訳します）; アクセシビリティ権限ステータス（System Settings へのショートカット付き）（他には権限不要）、「Dock が見えない理由」診断
- **使い方** — ジェスチャーとボタン
- **情報** — バージョン、更新チェック、製品ページと開発日記リンク、Star ボタン

アプリは Dock にもアイコンを持つため、インストール後にそこから起動できます。

実行中にアプリケーションから再度アプリを開くと、メニューがポップアップ表示されます。

## 要件とテスト環境

| | |
|---|---|
| ハードウェア | Touch Bar を備えた Mac（MacBook Pro 2016 ～ 2022） |
| **テスト対象** | **MacBook Pro 13" (M1, `MacBookPro17,1`)、macOS 27.0、シングルディスプレイ、3 Space、Touch Bar を「拡張コントロールストリップ」に設定、Stage Manager オン** |
| Apple silicon (M1) | ✅ このマシンで開発・使用されています |
| Intel | ⚠️ **未確認。** ダウンロードはユニバーサルバイナリで、Intel スライスは M1 Mac で Rosetta 下で起動しますが、実際の Intel Touch Bar Mac で実行したことがありません。報告をお待ちしています |
| macOS バージョン | macOS 13 最小値でビルドされていますが、macOS 27.0 でのみテストされています。古いバージョンはテストされていません |

知っておくべきこと:

- **プライベート Apple API** を使用して、バックグラウンドアプリから Touch Bar を画面に保持します。そのため Mac App Store に掲載できず、将来の macOS アップデートで破損する可能性があります。プライベートインターフェースは実行時に解決されるため、1 つが消えた場合その機能はクラッシュせず自動的にオフになります; `swift tools/probe-private-api.swift` を実行して、あなたの macOS がまだ持っているものを確認できます。
- Dock は **全** Touch Bar を使用するため、システムコントロールストリップ（明るさ、音量）は Dock がオンの間は隠れます。バーの右側の小さなコーヒーカップをタップして Dock を一時的に隠し、Touch Bar をシステムに返します（10 ～ 60 秒後に自動的に戻ります、デフォルトは 20 秒 — または、画面が完全に暗くなっていた場合は明るさが上がるとすぐに戻ります）。メニューで「Touch Bar に Dock を表示」をオフにすることもできます。
- 左から右の順序: ピン留めされていない実行中アプリ（最新のものが最初）→ 区切り → Finder → Dock 順でピン留めされたアプリ → 区切り → ゴミ箱。新しく起動されたピン留めされていないアプリは左に表示されます; 開いているアプリ間の切り替えはそれらを並べ替えません。ゴミ箱をタップして Finder で開きます。
- Stage Manager がオンの場合、macOS はウィンドウ変更をアニメーション化するため、ウィンドウが画面に表示されるまで約 0.5 秒かかります。タップされたアプリは約 40 ms で最前面アプリになり、残りはシステムのアニメーションです。

## インストール

1. [Releases](https://github.com/hooosberg/DockTouchBar/releases/latest) から `DockTouchBar-<version>.dmg` をダウンロードします。
2. それを開き、**DockTouchBar** を **Applications** にドラッグしてから起動します。Dock アイコンがメニューバーと Touch Bar に表示されます。

> DMG は Developer ID 証明書で署名され、**Apple によって公証**されているため、他のアプリと同じように開きます。macOS は最初の起動時の確認のみ求めます。ソースからコンパイルしたいですか？[ソースからのビルド](#ソースからのビルド)を参照してください。

### アクセシビリティ権限（オプション）

アクセシビリティにより、デスクトップ間ウィンドウ切り替え、ダブルタップ最小化、中央/最大化、Finder のウィンドウを閉じる、確認ダイアログの検出、Fn 譲渡が有効になります。なしでは、基本的な起動と有効化は利用可能のままですが、これらの機能は制限されます。

1. メニューバーアイコン → **設定...** → **権限** → **オンにする...** (与えられると **アクセシビリティ: オン** と読み込まれます)
2. System Settings → プライバシーとセキュリティ → アクセシビリティで、DockTouchBar をオンにします。

オンにした後も要求し続ける場合、古いエントリは古い状態です（これはアプリの署名が変更されたときに発生します）: リストで DockTouchBar を選択し、**−** をクリックしてから、もう一度追加します。または、`tccutil reset Accessibility com.maohuhu.docktouchbar` を実行して、ステップ 1 を繰り返します。

### タップがデスクトップを切り替えない場合

それが発生した直後に、リポジトリのクローンからこれを実行してください。読み取り専用で、アプリがそのアプリのウィンドウを判断した方法を出力します（どのウィンドウが存在する、各ウィンドウはどのデスクトップにあるか、どれが実際のウィンドウか、どれが発生するか）:

```bash
tools/diagnose-switch.sh com.google.Chrome
```

## Dock が見えない?

最も一般的な原因: System Settings → キーボード → 「Touch Bar に表示」が「F1、F2 など キー」に設定されている場合、全 Touch Bar が機能キーで埋まります。1.16 からアプリはこれを検出し、最初の起動時に「拡張コントロールストリップ」に切り替えることを提案します。また、メニューバーメニューで「診断: Dock が見えない理由は?」をクリックして、考えられるすべての原因を確認し、フィードバック用にレポートをコピーできます。その後も Fn を保持すると F1 ～ F12 が表示されます。

## ソースからのビルド

Xcode コマンドラインツールが必要です。

```bash
git clone https://github.com/hooosberg/DockTouchBar.git
cd DockTouchBar
scripts/install.sh      # ビルド → /Applications にコピー → 起動
scripts/make-dmg.sh     # build/DockTouchBar-<version>.dmg
```

署名証明書がない場合、ビルドは臨時署名にフォールバックします。それは機能しますが、macOS は臨時ごとの再ビルドを新しいアプリとして扱うため、毎回アクセシビリティを再度認可する必要があります。`SIGN_IDENTITY="Apple Development: …"` (または Developer ID 証明書) を設定して、1 つの安定した ID を保持します。
